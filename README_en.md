# Arcadia Nexus

[Deutsch](README.md) · **English**

Arcadia Nexus is a collection of mini-games for World of Warcraft.

## Installation

The released version can be installed via CurseForge. For manual installation, copy the `ArcadiaNexus` folder to:

`World of Warcraft/_retail_/Interface/AddOns/`

## Reporting issues

Bug reports and suggestions are welcome via this project's GitHub Issues. Please describe the problem, the game version you are using, and the steps required to reproduce it.

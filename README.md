# Arcadia Nexus

Arcadia Nexus ist eine Sammlung von Minispielen für World of Warcraft.

## Installation

Die veröffentlichte Version kann über CurseForge installiert werden. Bei einer
manuellen Installation muss der Ordner `ArcadiaNexus` nach
`World of Warcraft/_retail_/Interface/AddOns/` kopiert werden.

# Arcadia Nexus

Arcadia Nexus is a collection of mini-games for World of Warcraft.

## Installation

The released version can be installed via CurseForge. For manual installation, copy the `ArcadiaNexus` folder to:

`World of Warcraft/_retail_/Interface/AddOns/`

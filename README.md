# Arcadia Nexus

Arcadia Nexus ist eine Sammlung von Minispielen für World of Warcraft.

## Installation

Die veröffentlichte Version kann über CurseForge installiert werden. Bei einer
manuellen Installation muss der Ordner `ArcadiaNexus` nach
`World of Warcraft/_retail_/Interface/AddOns/` kopiert werden.

## Fehler melden

Fehlerberichte und Vorschläge sind über die GitHub Issues dieses Projekts
willkommen. Bitte beschreibe das Problem, die verwendete Spielversion und die
Schritte, mit denen es reproduziert werden kann.

Pull Requests werden nur nach vorheriger Absprache angenommen.
